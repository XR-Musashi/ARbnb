Problem Space

Guests Are Lost in Unfamiliar Spaces

Airbnb guests arrive at properties they've never seen — no spatial context, no guided orientation, and no persistent instructions anchored to the real world.

🗺️

No Spatial Context

Guests wander through unfamiliar layouts — where is the WiFi router, the boiler switch, the emergency exit?

📋

Host Overhead

Hosts write long check-in PDFs that guests rarely read. Repeated questions eat into time for both parties.

🔄

No Persistence

Paper notes vanish and text instructions lose meaning without physical context. Every new guest starts from zero.

The Solution

Spatially-Anchored Instructions in AR

📱

Guest AR App

Floating waypoint arrows guide guests through the property. Proximity-triggered annotation panels — anchored to real objects — surface instructions exactly where they're needed.

Unity 6ARCore SLAM
🖥️

Host Dashboard

Hosts author annotations using a browser-based editor with 2D floor plan view and an interactive 3D model viewer. No AR device required to set up the property.

Spatial Persistence

Cloud Anchor Two-Phase Flow

Phase 1 · First Guest
🏗️

Host Anchor

Panels appear at raw worldX/Y/Z. HostAnchorAsync runs in background. Result cloudAnchorId saved to DB via POST /api/anchors.

Phase 2 · Subsequent
📍

Resolve Anchor

Panels start at raw positions, then SnapToAnchor re-parents each panel to the resolved ARAnchor once ResolveAnchorAsync completes.

Fallback
🔒

Local Fallback

If CloudAnchorService is not wired in the Inspector, AnnotationManager skips cloud sync. Panels remain at raw world positions using local ARAnchorManager.

⚙️

CloudAnchorService.cs — wraps ARCore Extensions Cloud Anchor API. HostAnchorAsync(Vector3) and ResolveAnchorAsync(string cloudAnchorId). Requires ARAnchorManager assigned in Inspector. Markerless ARCore SLAM only — no image targets.

Design Rationale

Key Architectural Decisions

🔒

No Cloud Services (except Google Cloud Anchors)

Auth and file storage are fully local. Supabase has been removed entirely. Keeps stack simple and offline-capable.

🎯

Markerless ARCore SLAM Only

No image targets or QR codes. Pure environment-based tracking for a seamless guest experience — no physical setup required.

📐

3D Model for Precise Annotation Placement

Hosts place annotations in a 3D model viewer. Coordinates map directly to AR world space (after Z-negation) — far more accurate than 2D-only floor plan clicks.

🎨

No Canvas/UGUI in AR (World-Space Only)

World Space Canvas does not render reliably in Unity 6 URP AR. Annotation panels are built as Quad + 3D TMP labels with URP-compatible materials, entirely in code.

📡

LiDAR Is Enhancement Only

Samsung S25 Ultra has no LiDAR. All base features work without a depth sensor — LiDAR support is a future enhancement path, not a dependency.
